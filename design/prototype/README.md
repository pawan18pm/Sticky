# Sticky — travel memory app prototype

Upload travel photos, see them pinned on a map, tap a place to relive the memory.

Live, clickable canvas: https://claude.ai/artifact/VXR7bekzHDw7iZjMXX8973

## Files

These are the source files of the design canvas (Design Component `.dc.html` format).
They render inside the claude.ai design canvas, not as plain web pages.

| File | Screen |
|---|---|
| `canvas.json` | Canvas layout: artboard positions, titles, notes (feature set, onboarding principles) |
| `Main.dc.html` | Onboarding 1 — Welcome |
| `Permissions.dc.html` | Onboarding 2 — Photo & location access |
| `Import.dc.html` | Onboarding 3 — Auto-import trips |
| `MapReady.dc.html` | Onboarding 4 — Your map is ready |
| `MapHome.dc.html` | Map (home) with pins, year filters |
| `Memory.dc.html` | Memory detail |
| `AddMemory.dc.html` | Add a memory |
| `Trips.dc.html` | Trips timeline & travel stats |
| `Resurface.dc.html` | On this day + share |

## Editing

Ask Claude to edit a screen (e.g. "make the map home darker"). Claude updates the live
canvas; re-sync the files here afterwards so the repo matches the canvas.
